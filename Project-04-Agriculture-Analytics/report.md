# 🌾 Agriculture Analytics Dashboard

## 📌 Project Overview

The Agriculture Analytics Dashboard is a data analysis project built using **NumPy** and **Matplotlib**. The objective of this project is to analyze agricultural data from different districts and generate meaningful insights through statistical analysis and visualizations.

The dashboard provides a comprehensive overview of agricultural production, crop yield, rainfall, fertilizer usage, water consumption, and district-wise performance.

---

# 🎯 Objectives

- Analyze agricultural production data.
- Compare production across districts.
- Study the impact of rainfall on crop yield.
- Analyze fertilizer and water usage.
- Identify high-performing districts.
- Visualize agricultural statistics using professional dashboards.

---

# 🛠 Technologies Used

- Python
- NumPy
- Matplotlib

---

# 📂 Dataset Information

The dataset contains agricultural information including:

- District
- Crop
- Rainfall (mm)
- Temperature (°C)
- Soil Moisture (%)
- Fertilizer Usage (kg)
- Water Usage (L)
- Crop Yield (Ton)
- Total Production (Ton)

---

# 📊 Analysis Performed

## 1. Dataset Exploration

- Loaded the dataset using NumPy.
- Checked dataset dimensions.
- Extracted individual columns.
- Identified unique districts and crop types.

---

## 2. Statistical Analysis

Calculated:

- Total Production
- Average Production
- Average Yield
- Maximum Production
- Minimum Production
- Average Rainfall
- Average Temperature
- Average Soil Moisture
- Average Fertilizer Usage
- Average Water Usage

---

## 3. Rainfall Analysis

Studied rainfall distribution across districts and analyzed its relationship with agricultural production.

Insights:

- Districts with higher rainfall generally produced better yields.
- Rainfall showed a positive impact on crop productivity.

---

## 4. Yield Analysis

Analyzed crop yield statistics.

Calculated:

- Highest Yield
- Lowest Yield
- Average Yield

This helps identify high-performing agricultural regions.

---

## 5. Production Analysis

Compared production among districts.

Identified:

- Highest producing district
- Lowest producing district
- Overall production trends

---

## 6. Correlation Analysis

Correlation coefficients were calculated between:

- Rainfall vs Yield
- Fertilizer vs Production
- Water Usage vs Yield
- Soil Moisture vs Yield
- Temperature vs Yield

This helped understand relationships between agricultural factors.

---

## 7. Ranking Analysis

Generated rankings for:

- Top 5 districts by production
- Bottom 5 districts by production
- Top 5 districts by yield
- Top 5 rainfall districts
- Top fertilizer usage districts
- Top water usage districts

---

## 8. Efficiency Analysis

Calculated:

### Water Efficiency

Production per liter of water.

### Fertilizer Efficiency

Production per kilogram of fertilizer.

These metrics help identify resource-efficient agricultural practices.
