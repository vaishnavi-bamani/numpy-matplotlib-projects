# Student Performance Dashboard Report

## Objective

Analyze student academic performance using NumPy and visualize the insights with Matplotlib.

## Dataset

- Students: 20
- Subjects:
  - Mathematics
  - Science
  - English
- Attendance

## Analysis

### Subject Performance

English achieved the highest average score, followed closely by Science and Mathematics.

### Attendance

Students with higher attendance generally performed better, indicating a positive relationship.

### Overall Marks

Most students scored between 70 and 90 marks.

### Distribution

The box plot shows that marks are relatively consistent across all subjects.

### Pass Percentage

All students passed in this dataset, resulting in a 100% pass rate.

## Conclusion

NumPy enabled statistical analysis, while Matplotlib transformed the data into meaningful visualizations that make academic performance easier to understand.
